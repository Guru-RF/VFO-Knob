VFO-Knob

 

This knob still uses the shipped password (admin/admin). Anyone on this network can key your transmitter with it — set your own below.

Status

Radio

The radio's own network user. On the IC-705: MENU » SET » WLAN Set » Remote Settings — Network Control ON, and a Network User with this name and password. The knob reaches the radio over WiFi, and applies changes here on its next boot.

You are on the USB cable. Over it the knob finds AetherSDR on this computer by itself; this host is what it uses on WiFi. Open this page over WiFi and my IP fills it in.

The reflector's name, as SvxLink knows it: its SRV record says which host and port to use (be.svx.link is reflector.be.svx.link:5300). The port counts only for a name without one. Changes here apply on the knob's next boot.

Station

Leave both coordinates empty to publish no position.

Talkgroups

A + after a number raises its priority, up to +++: traffic there takes the knob off a quieter talkgroup. With both lists empty the dial steps through every talkgroup the reflector's portal names. The lock on the knob's face stops all switching.

Station and talkgroup changes apply when saved: the knob logs in again.

Certificate

The reflector knows a station by a certificate it signs. The request goes with the callsign and email above; the knob makes its key first, which takes up to a minute. Some reflectors sign at once, others wait for their sysop, and the knob keeps asking until the certificate arrives. It renews by itself.

Delete the key

The reflector ties the callsign to this key. With a new key the sysop has to remove the old certificate before signing again.

WiFi

Used when the knob is powered from a charger rather than a computer. Applies on the next boot.

Audio

Volume and mic gain take effect immediately.

Turning the knob, touching the screen or transmitting all count as use. Dimming leaves the frequency readable; going dark turns the backlight off.

Access

Guards this page only. It is sent unencrypted, so treat it as a lock on the door rather than a safe.

Firmware

There is one firmware per radio, and the knob runs one at a time. Switching installs the other radio's latest release.

The knob checks by itself on WiFi. Over the USB cable it has no route to the internet, so this page checks and does the downloading for it — same image, same signature check.
